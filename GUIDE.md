# Свой VPN в 2026: подробная инструкция

**Выбранный способ:** VPS за границей + панель **3x-ui** (Xray) с двумя подключениями:

1. **VLESS + TCP + Reality** (порт 443) — основное, самое быстрое.
2. **VLESS + XHTTP + Reality** (порт 8443) — запасное, на случай если основное начнут резать.

Оба подключения раздаются клиентам **одной ссылкой-подпиской**: в приложении Happ / v2RayTun / Hiddify появятся оба сервера, и если один перестал работать, переключаетесь на второй в один тап.

### Почему именно так

| Вариант | Итог |
|---|---|
| WireGuard / OpenVPN | В России заблокированы — не подходит |
| AmneziaVPN (AmneziaWG) | Проще всего, но меньше гибкости. Хороший запасной план (см. раздел 9) |
| Hysteria2 | Хорош как резерв, но нужен домен и отдельная панель |
| **3x-ui + VLESS Reality + XHTTP** | Самый популярный и проверенный вариант, веб-панель без терминала, несколько протоколов на одном сервере, лимиты и статистика по клиентам, подписки |

С конца 2025 года VLESS TCP Reality на 443 порту у части провайдеров начали замедлять (много коротких TLS-соединений). Поэтому второе подключение на XHTTP — обязательная страховка, а не опция.

---

## 0. Что понадобится

- Компьютер (Windows / macOS / Linux) — для настройки.
- 300–500 ₽ в месяц на VPS.
- 30–40 минут.

## 1. Аренда сервера

Требования:
- **Страна:** Нидерланды, Германия, Финляндия, Польша (низкий пинг из России).
- **Тариф:** минимальный — 1 vCPU, 1 ГБ RAM, 10+ ГБ диска.
- **ОС:** Ubuntu 24.04.
- **Трафик:** безлимит или от 1 ТБ/мес.
- **Оплата:** российская карта / СБП / крипта.

Небольшие хостинги блокируют реже крупных (Hetzner, DigitalOcean, OVH). Возьмите сначала на месяц или с почасовой оплатой, проверьте скорость, потом продлевайте.

После оплаты в панели хостинга появятся **IP-адрес**, логин **root** и **пароль** — запишите их.

> Если у хостинга есть собственный файрвол в личном кабинете, откройте в нём порты: 22, 443, 8443 (TCP), а также порты панели и подписки, которые появятся на шаге 3.

## 2. Подключение к серверу

Установите **Termius** (termius.com) или используйте встроенный терминал:

- **Windows:** Пуск → «Терминал» (или PowerShell)
- **macOS:** Программы → Утилиты → Терминал

```bash
ssh root@ВАШ_IP
```

На вопрос `Are you sure...` ответьте `yes`, затем вставьте пароль (символы не отображаются — это нормально) и нажмите Enter.

Сразу обновите систему и смените пароль root на свой надёжный:

```bash
apt update && apt upgrade -y
passwd
```

## 3. Установка панели 3x-ui

```bash
bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)
```

Скрипт задаст несколько вопросов:

1. **Порт панели** — нажмите Enter (выберет случайный, так безопаснее).
2. **SSL-сертификат** — выберите вариант для **IP-адреса** (домен не нужен). Порт для проверки — 80, Enter.
3. На IPv6 — просто Enter.

В конце скрипт выведет блок с **адресом панели, логином и паролем**. **Обязательно сохраните** его в заметки.

Если блок потерялся — в любой момент наберите `x-ui` на сервере: откроется меню, где можно посмотреть настройки или сбросить логин/пароль.

## 4. Вход в панель и базовая настройка

1. Откройте в браузере адрес панели из шага 3 (вида `https://ВАШ_IP:ПОРТ/СЛУЧАЙНЫЙ_ПУТЬ/`).
2. Войдите с выданными логином и паролем.
3. **Настройки панели → Безопасность:** смените логин и пароль на свои.
4. **Настройки панели → Подписка:** включите подписку (Subscription). Запомните порт подписки (по умолчанию 2096).
5. Сохраните и перезапустите панель (кнопки вверху).

## 5. Выбор сайта для маскировки (SNI)

Reality маскирует трафик под соединение с реальным сайтом. Сайт должен быть **иностранным, не заблокированным в РФ, с поддержкой TLS 1.3 и HTTP/2**.

**Простой вариант** — взять один из проверенных: `www.nvidia.com`, `github.com`, `www.samsung.com`, `dl.google.com`, `www.microsoft.com`.

**Лучший вариант** — найти сайт, который хостится рядом с вашим сервером (так трафик выглядит естественнее). Для этого есть утилита от разработчиков Xray — **RealiTLScanner**:

```bash
cd /root
wget https://github.com/XTLS/RealiTLScanner/releases/latest/download/RealiTLScanner-linux-64
chmod +x RealiTLScanner-linux-64
./RealiTLScanner-linux-64 -addr ВАШ_IP
```

Через минуту-две остановите сканирование (Ctrl+C). Из найденных доменов выберите тот, что открывается в браузере как нормальный сайт (а не пустая заглушка), и **не принадлежит Cloudflare**.

## 6. Создание подключений

### 6.1. Основное: VLESS + TCP + Reality (порт 443)

Панель → **Подключения → Добавить подключение**:

| Поле | Значение |
|---|---|
| Примечание | `reality` |
| Протокол | `vless` |
| Порт | `443` |
| Транспорт | `TCP (RAW)` |
| Безопасность | `Reality` |
| uTLS | `chrome` |
| Target (Dest) | `выбранный-сайт:443` |
| SNI | `выбранный-сайт` |
| Ключи | нажмите **Get New Cert** (сгенерирует пару ключей) |
| Short IDs | оставьте сгенерированные |
| Клиент → Email | имя клиента, например `phone` |
| Клиент → Flow | **`xtls-rprx-vision`** (обязательно!) |

Нажмите **Создать**.

### 6.2. Запасное: VLESS + XHTTP + Reality (порт 8443)

Ещё раз **Добавить подключение**:

| Поле | Значение |
|---|---|
| Примечание | `xhttp` |
| Протокол | `vless` |
| Порт | `8443` |
| Транспорт | `XHTTP` |
| Path | любой, например `/api/v2/stream` |
| Mode | `auto` |
| Безопасность | `Reality` |
| uTLS | `chrome` |
| Target / SNI | тот же сайт, что и в 6.1 (можно другой) |
| Ключи | **Get New Cert** |
| Клиент → Email | `phone-x` (email должен отличаться от первого подключения) |
| Клиент → Flow | **пусто** (Vision с XHTTP не используется) |
| Клиент → Subscription | **тот же Sub ID**, что у клиента `phone` в первом подключении |

> Одинаковый **Sub ID** у клиента в обоих подключениях — это то, что объединяет их в одну подписку. Скопируйте Sub ID из клиента первого подключения (иконка редактирования клиента) и вставьте во второй.

### 6.3. Защита сервера (рекомендуется)

**Настройки Xray → Базовые:** включите блокировку BitTorrent (чтобы на ваш IP не пришли жалобы) и блокировку приватных IP.

Сохраните и нажмите **Перезапустить Xray**.

Если на сервере включён ufw — откройте порты:

```bash
ufw allow 22/tcp
ufw allow 443/tcp
ufw allow 8443/tcp
ufw allow ПОРТ_ПАНЕЛИ/tcp
ufw allow 2096/tcp     # порт подписки
```

## 7. Подключение устройств

### Получить ссылку

В списке подключений раскройте клиента → иконка **QR / информация**:
- **Ссылка подписки** (`https://ВАШ_IP:2096/sub/...`) — **используйте её**: в ней сразу оба подключения, и при изменениях на сервере клиенты обновятся сами.
- Отдельные ссылки `vless://...` — если приложение не поддерживает подписки.

### Приложения

| Устройство | Приложение | Как добавить |
|---|---|---|
| Android | **Happ**, v2RayTun, Hiddify | «+» → Импорт из буфера / Сканировать QR |
| iPhone / iPad | **Happ**, v2RayTun, Streisand | «+» → Из буфера / QR |
| Windows | **Happ**, Hiddify, v2rayN | «+» / Серверы → Импорт из буфера |
| macOS | **Happ**, Hiddify, FoXray | «+» → Из буфера |
| Android TV | Happ, v2RayTun | Через QR с телефона |

Подключитесь и проверьте IP на `2ip.ru` — должен показываться IP сервера и его страна.

### Раздельное туннелирование (очень желательно)

Чтобы российские сайты (банки, Госуслуги, маркетплейсы) открывались напрямую, а через VPN шли только заблокированные:

- **Happ / v2RayTun / Hiddify:** настройки → Маршрутизация (Routing) → включить режим **«Россия напрямую» / Bypass RU** (geoip:ru и geosite:ru — direct).
- **v2rayN:** внизу окна выберите маршрутизацию **«В обход РФ»** (Bypass mainland/RU).

Плюс: меньше расходуется трафик к зарубежным серверам, российские сервисы не ругаются на иностранный IP.

### Для каждого человека/устройства — свой клиент

Добавляйте клиентов кнопкой **«Добавить клиента»** в каждом подключении (с общим Sub ID для одного человека). Можно задать лимит трафика и срок действия. Удалить клиента = отключить доступ.

## 8. Если перестало работать

Действуйте по порядку:

1. **Переключитесь на второй сервер (XHTTP)** в приложении.
2. **Поменяйте SNI** на другой сайт (шаг 5) в обоих подключениях → обновите подписку в приложении.
3. **Поменяйте порт** основного подключения (например, на 2053 или 8880).
4. **Проверьте сервер**: `x-ui status`, логи — `x-ui` → пункт с логами.
5. **IP сервера заблокирован** (не открывается вообще ничего, даже панель): смените IP в хостинге или закажите новый VPS — вся настройка займёт 20 минут. Бэкап базы панели: `x-ui` → резервная копия, либо файл `/etc/x-ui/x-ui.db`.

Обновление панели: `x-ui` → Update.

## 9. Запасные и продвинутые варианты

- **AmneziaVPN — самый простой резерв.** Скачайте приложение Amnezia на ПК, выберите «Свой сервер», введите IP/логин/пароль **другого** VPS — приложение само поставит **AmneziaWG**. На iPhone из российского App Store вместо Amnezia используйте приложение **Default VPN**. Ставить Amnezia на тот же сервер, что и 3x-ui, не рекомендуется (конфликт портов 443).
- **Hysteria2** (UDP, панель Blitz) — работает, когда режут TCP. Нужен (бесплатный) домен.
- **XHTTP через Cloudflare CDN** — IP сервера скрыт за Cloudflare, заблокировать сложнее. Нужен свой домен.
- **Каскад (российский VPS → зарубежный VPS)** — помогает при «белых списках» на мобильном интернете и при возможных ограничениях трафика к иностранным серверам. На российском сервере тоже ставится 3x-ui; ссылка зарубежного сервера добавляется как «Исходящее подключение», а в маршрутизации российские IP/домены идут напрямую, остальное — на зарубежный сервер.

## 10. Безопасность

- Ссылки и подписки — это пароли. Не публикуйте их.
- Не делитесь данными для входа в панель и root-паролем.
- Раз в месяц обновляйте систему (`apt update && apt upgrade -y`) и панель (`x-ui` → Update).
- Для продвинутых: вход по SSH-ключу вместо пароля и смена SSH-порта.

### Альтернатива без панели

В этом репозитории есть скрипт [`xray-reality/install.sh`](xray-reality/install.sh), который ставит VLESS + Reality одной командой без веб-панели. Подходит, если панель не нужна, но в нём нет XHTTP и подписок — для большинства 3x-ui удобнее.
